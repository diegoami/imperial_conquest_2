# Collaboration guidance for Imperial Conquest 2

Keep the user informed while working on this project. At the start of a task, describe the concrete steps you intend to take. During the task, give regular progress updates that explain what you examined, what the evidence shows, what you changed and why, what remains uncertain, and what you will check next. Do not leave the user without an update for more than about a minute during active work.

When reverse-engineering the original game, distinguish observations from inferences and say which save, screenshot, recording, or binary structure supports a conclusion. Explain important implementation choices in plain language. At the end, report the outcome, relevant verification, remaining limitations, and where the user can see the result.

These updates should make the work and decisions visible without exposing private chain-of-thought or overwhelming the user with raw command output.
