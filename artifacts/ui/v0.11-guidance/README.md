# Campaign-guidance captures

Generated by `CampaignGuideCheck` with Godot 4.7.2 mono on Windows, NVIDIA OpenGL compatibility renderer. Images cover four color schemes at 1500×850 and at 1000×650 logical pixels scaled to 1500×975 physical pixels (150%). Authored application UI only.

The scene selects every shipped campaign through real row controls, checks its actual background/advice/abstraction labels, scrolls to the final rules paragraph, and checks Continue remains visible. Keyboard Down selects Improved and refreshes the panel; the capture shows that selection. Content is data-driven from `data/campaign-guides`, with historical evidence and provisional recommendation limits in [the maintained briefs](../../../docs/campaign-guides.md).
