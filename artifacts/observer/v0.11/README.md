# Continuous observer control capture

`loop-controls.png` is captured by `ObserverLoopCheck -- --capture` from our own
authored client at 1920×1080 with clean test display settings. It shows the real
Classical observer and continuous-loop control. This is UI placement evidence,
not whole-campaign, moving-camera or original-game fidelity acceptance.

The deterministic lifecycle/control checks are `ObserverLoopCheck`,
`ObserverModeCheck`, `ObserverPlaybackCheck` and `ContinuousObserverTests`.
The owner-requested broader toolbar/panel compactness is separate under #1818.
