# ui-redesign-evaluation (archived)

**Question:** How does the UI look today against the user's complaints (impersonal font, loose and large panels), and which font pairings, palettes and compact type scale could replace it?

**Result:** Evaluated, not decided: every screen and dialog as it stands, four font pairings (Cinzel or Marcellus or Cormorant SC for display with Source Sans 3, IBM Plex Sans Condensed, Alegreya Sans or Fira Sans Condensed for body, all SIL OFL, bundled under `godot/Assets/Fonts/candidates/`), three palettes with measured WCAG contrast (all above 5:1), a compact type scale, and a windowed tour (`FontCandidatesTour`) that renders each candidate. The user chooses; the choice is recorded in the document's last section.

Full write-up, frozen: [archive/desktop-2026-10-20](https://github.com/diegoami/imperial_conquest_2/blob/archive/desktop-2026-10-20/docs/investigations/ui-redesign-evaluation.md).
