  - **#276, the parser half.** A fleet absorbed into another leaves its record behind with owner word `0xFFFF` and every other field intact (`IP012B.sav`, fleet 4). `SaveArmyTable.Parse` skips and reports that sentinel for armies (`SaveArmyTable.cs:79–83`); `SaveFleetTable.Parse` has no equivalent, so `FleetRecord.OwnerCode` (`SaveFleetTable.cs:106`) reads 65535 straight through into `IC2.Inspect --list-fleets`, `CorpusOutcomes.Generate` (`CorpusOutcomes.cs:91`) and `ArmyFleetFieldRangeSweepTests.cs:126`, which fails on the configured machine today. The import half is T21's (its Done-when 10, the user's decision of 2026-09-23 on #276).
  - **#213.** Two fixture resolvers disagree about where a save can live. `FixtureResolver` (T53) searches `saves-processed/`, `saves/` and `releases/<tag>/**`; `CorpusFileLocator` (T34, `SaveDirs` at `CorpusFileLocator.cs:18–19`) searches `saves/`, `saves-processed/` and `saves-processed/processed/`. A save that arrives only through a release is found by the named-fixture tests and silently skipped by the corpus sweep. One list of locations, in one place.
  - **#218.** N11: `LocalAssets.WasRequested` (T53's fix for a broken fixtures source passing green) is asserted by nothing; a reviewer set both assignments to `false` and CI stayed green. N3: T53 Done-when 2's message never reaches a CI log, because a passing test's output is hidden at `dotnet test`'s default verbosity. N12 (a blank `IC2_FIXTURES_DIR` is unset-equivalent) and N13 (the fork-push guard) are decided edges, not work. N14 is a documentation clause for when #213 lands.

- **Hazards**:
  - **Never renumber a fleet.** `FleetRecord.Index` is the slot number in the original's own table. A skip that reindexes the survivors makes every later slot reference wrong, and T21 maps these records.
  - **The sentinel is specific, not a widened range.** `SaveFleetTable` validates no owner range today, and this task adds none: it skips `0xFFFF` and nothing else.
  - **A release cache legitimately repeats a save that is also in `saves/`.** `CorpusFileLocator` throws on a duplicated name today. The Done-when 4 rule must not make the configured-corpus sweep throw on a cache that copies a save it already has; say what the rule is (for example, identical bytes count as one file) and why.
