# T274 — Faithful trade sweep ordering

Task issue: [#1737](https://github.com/diegoami/imperial_conquest_2/issues/1737). Corrects [#1732](https://github.com/diegoami/imperial_conquest_2/issues/1732), allocated by the owner to v0.9.2 on 2026-11-03.

## Contract

Within the existing scored AI driver, order Original-AI fresh trades by FUN_0044FB7C's two sweeps. Every successive strictly leading eligible war candidate is skipped in the first sweep, not just the final winner. The second sweep revisits those still eligible in nation-table order if live capacity permits. Read the same busy, protection, neighbour, power and relation gates as the existing war-target query; a human candidate can update the running best although it cannot trade. Do not filter a skipped nation permanently.

Source: [research `264098b`, primary report §1a](https://github.com/diegoami/imperial-conquest-2-research/blob/264098b/docs/reports/decompiled-ai-offers-to-human-seats.md#1a-fun_0044fb7c-an-ai-seats-own-turn-confirmed-decompile-key-compares-checked-in-the-listing), and its diplomacy-longrun D3. This is code-confirmed ordering, not an observed deterministic divergence in that 330-seat-turn sample; no new native Windows, chance-distribution or global-RNG parity is claimed.

Owns `AiOwnDiplomacyRule`, `AiDiplomacyPhase`, `AiTurn`'s transient first-scan context, focused regression tests and factual documentation. Preserve existing war/alliance proposal priorities and RNG streams, T251's closing swap pass, Improved behavior, save formats, presets and unrelated command rules. Retain the first scan's leader set across higher-priority war/alliance writes; becoming busy afterward must not discard the original exclusions. Only trade eligibility/caps are re-read live. The set is local to an invocation and never saved or static. This contract does not replace the complete greedy driver or emulate the original's uninitialised busy flag.

## Done when

1. Real AI-turn dispatch with multiple successive war leaders and a binding three-trade cap picks the first-sweep partners before skipped leaders. Reverting only the trade ordering fails that regression; excluding only the final best also fails.
2. Nonbinding capacity permits skipped candidates in the later sweep, in table order. Verify busy/equal-ratio/non-neighbour/protected/human cases, live partner caps and eligibility, repeatability and Improved controls. A real war-roll hit retains the pre-declaration leader set; a later invocation starts fresh. An isolated recomputation-after-war mutation must fail. Pure queries consume no RNG or state and old war-target results remain green.
3. Run full solution and relevant diplomacy/AI/determinism/soak/CLI regressions; explain any golden change without changing player scripts, seeds or fixture lineage. Green hosted CI precedes merge.
