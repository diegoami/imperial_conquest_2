#### T128 The battle screen's assets: 15 recolourable unit icons, the ground tile, the cursor and the toolbar glyphs

- **Design milestone**: M21 (the tactical battle, v0.5.0 *Battles*, [#496](https://github.com/diegoami/imperial_conquest_2/issues/496)). It adds the asset keys the battle screen (T127) draws, to both shipped packs, and the specification rows for them. **Labels**: `phase:3 lane:ui`
- **Branch**: `task/T128-battle-assets` · **Model/effort**: Sonnet / Medium · **Reviewer**: **Opus**/Medium **+ human visual review** (the tier rule decides; complex)
- **Start after**: none · **Merge after**: none. T127 starts after this task. It is **never in flight with** another task that edits either pack's `manifest.json` or the generator scripts.
- **Owns**:
  - `docs/asset-specification.md`: **only** §4.7's bullet "The original's tactical battle screen" (rewritten as the key table below) and §6's key list (the new keys appended);
  - `assets/packs/placeholder/manifest.json` and `assets/packs/authored/manifest.json`: **only** the new `battle.*` keys;
  - `assets/packs/placeholder/battle/**` and `assets/packs/authored/battle/**` (new);
  - `scripts/generate-placeholder-assets.ps1`: **only** a new battle section;
  - `scripts/generate-authored-assets.py` and `assets/prompts.json`: **only** the new keys' entries;
  - `godot/Assets/BattleAssetKeys.cs` (new, Godot-free key constants) and `godot/Assets/BattleIconTint.cs` (new: the three-region recolour);
  - `tests/IC2.Engine.Tests/Ui/Assets/BattleAssetKeysTests.cs` (new) and its one `<Compile Include>` line in `tests/IC2.Engine.Tests/IC2.Engine.Tests.csproj`.
- **Scope**:
  - **Protects**: that every key the battle screen draws exists in both packs and the drift test, with the size thresholds and three recolourable regions the decompile gives; and that no existing key, file or the strategic §4.1 icons change. Forbidden: a file taken from the original installation (no bitmap, resource or screenshot of the original enters a pack), an existing key renamed or redrawn.
  - **The inventory** **[confirmed: code and the `TBATTLEMAP` resource, static, [`2026-10-04-decompiled-tactical-battle-rules.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/2026-10-04-decompiled-tactical-battle-rules.md) §10]**: `battle.unit.<type>.<small|medium|large>` (15 keys, 32 × 32, the size by `min(2, troops div (standardBattalionSize div 3))`); `battle.ground` (one grass tile); `battle.cursor`; `battle.toolbar.<unit_moves|friendly_units|enemy_units|cancel_selection|end_turn|change_pauses|computer_general|surrender>` (eight 20 × 20 glyphs) [designed: the key names, following §1.5's convention]. The pictures are the clone's own: the report's descriptions (a spear and sword for light infantry, a shield with crossed swords for heavy infantry, …) are a guide, not a copy.
  - **The recolour.** Each unit icon has three recolourable regions, as the original's purple `0x800080`, white and blue are replaced by the nation's three colours **[confirmed: code, `FUN_0044A6C8`]**. The original's per-nation colour triples were not read, and the clone's palette (§2) has one colour per nation, so the triple is **[designed]**: region 1 the nation's palette colour, region 2 white, region 3 the palette colour darkened [designed: a placeholder for the human visual review]. `BattleIconTint` holds that rule, Godot-free.
- **Done when**:
  1. `BattleAssetKeysTests` asserts the 25 keys exist in both manifests and resolve to files of the stated sizes, and that each unit icon file contains the three marker colours the tint replaces; it fails on `main` and passes after.
  2. The drift test (asset-specification §5) passes with the new keys listed in §6.
  3. `pwsh scripts/generate-placeholder-assets.ps1` regenerates the placeholder battle files byte-identically on a second run.
  4. `git diff --stat origin/main -- assets/packs` lists only `battle/**` files and the two manifests, and `AssetPackSelectionCheck` passes.
  5. `dotnet build IC2.sln` and `dotnet test IC2.sln` are green, and the diff lists only Owns paths.
- **Hazards**:
  - **The human visual review** looks at the 15 icons recoloured for three nations side by side, the ground, the cursor and the eight glyphs, as screenshots in the PR. It is the reviewer's gate, not a numbered Done-when.
  - **The standing rule**: no file originating from the user's original installation enters either pack ([release-plan.md §5](../release-plan.md#5-release-checklist) item 13). Describe, never extract.
