- **Done when**:
  1. **Typed path errors (#284 N3, R2-N2).** An empty document path with a `dataFile`, and a `dataFile` containing NUL or any other invalid path character, each throw a `GameDataException` subtype that names the problem, never an `ArgumentException`. One test for each.
  2. **Accurate messages (#284 R2-N3).** `"nul"` and `"."` are rejected with a message that says what is wrong with them, not that they escape the directory. The case rule for the directory-prefix compare is stated in a remark and tested with `"../WORLDS/ok.b64"`. The missing-sidecar message names the path once.
  3. **A killed run cannot leave the sidecar deleted (#284 R2-N1).** Either the backup goes to the temp directory, or the test restores the sidecar from a leftover `.bak` before it starts; the PR says which. A test or a scripted demonstration shows it: delete the sidecar, leave a `.bak`, run the test, and the sidecar is back and the test passes.
  4. **The namespace (#284).** `QuarterlyEconomySystemTests.cs`' reference and its `cref` use `IC2.Engine.Serialization.GameDataValidation`, fully qualified.
  5. **A failed rename (#286 item 1).** The task decides between a Windows-conditional test (hold the target open so the rename fails, then assert the previous save's bytes are intact) and documenting the gap in `WriteFile`'s remark, and the PR says which and why. If a test: it skips on other platforms with a stated reason and never passes silently, and the mutation that empties the target on a rename failure fails it on Windows.
  5a. **Folded bug ([#346](https://github.com/diegoami/imperial_conquest_2/issues/346), added 2026-09-25): a missing migration step says so.** A version between `MinimumSupportedVersion` and `CurrentVersion` that has no migration step is rejected with a message naming the missing step, never "written by a newer build". A test proves every version from `MinimumSupportedVersion` to `CurrentVersion − 1` has a step, so bumping `CurrentVersion` without one fails that test. Show the mutation: remove the `1 =>` step and the test fails, naming it.
  5b. **Folded follow-up ([#411](https://github.com/diegoami/imperial_conquest_2/issues/411) S2, added 2026-09-26): T86's two references are validated.** `ValidateState` rejects a state in which `GameState.Neighbours` names a nation that doesn't exist, as a key or inside a list, and a state in which a nation's `ConqueredBy` names one that doesn't exist. Each error is typed and names the dangling id. There is one test for each, and each fails when its check is removed. A null `Neighbours`, which is still the fallback for a state that carries no neighbour set, and a null `ConqueredBy` both stay valid, with a test showing each.
  6. `dotnet build IC2.sln` and `dotnet test IC2.sln` green, and the diff lists only Owns paths.
