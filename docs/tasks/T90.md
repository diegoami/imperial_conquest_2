- **Scope**: The source is the decompile, as recorded on #407. The research report [`decompiled-elimination-cleanup.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/decompiled-elimination-cleanup.md), section "Why defection almost never empties a nation", states the rule but tags it `[derived]`.
  - `FUN_0044BA1C` (`all_app_functions.txt` :50108–50141), the cascading-defection sweep, gates each candidate city on `FUN_0044B8D0(city) == 0`. It checks once before the distance test, and again just before `FUN_0044BED8`. **[confirmed: decompile]**
  - `FUN_0044B8D0` walks all 16 nations' capital pointers (`DAT_00474AB4`, which is nation base `0x474670` plus `+0x444`, stride `0x494`). It returns 1 when the city is **any** nation's capital, with no check on whether that nation is alive. **[confirmed: decompile]**
  - T17 read this gate as "if not already contested" and implemented it as `CityState.UnderSiege`. **The original has no siege gate in this sweep.** The engine is missing the capital gate and has an invented siege gate in its place.
  - The sweep's other gates are unchanged: the owner, the distance `< 10`, the strength comparison with `/3` for an allegiant city, the loser's unity `< 650`, and loyalty `< 65`.
- **Done when**:
  1. **The capital gate.** A candidate that is some nation's capital never defects. There is one test for each case:
     - the loser's own capital;
     - a third nation's capital that the loser owns;
     - an eliminated nation's capital field that still names a city the loser owns, if the engine's state can hold that. If it can't, the PR says why.

     Removing the check fails these tests.
  2. **No siege gate.** A besieged non-capital candidate that passes every other gate now defects, with a test. Restoring the `UnderSiege` gate fails it.
  3. **#407's symptom.** A capture whose cascade used to take the loser's capital and last city leaves the capital with the loser, and the conquest rule decides the rest. There is a test through the real capture command.
  4. **Seeded outcomes.** Every seeded test, measurement or golden that changes is listed with its reason. The 50-seed soak keeps 0 rejected commands.
  5. `dotnet build IC2.sln` and `dotnet test IC2.sln` green, and the diff lists only Owns paths.
- **Hazards**:
  - **The second check.** The original repeats `FUN_0044B8D0` just before the defection. A defection in the same sweep writes no capital, so the repeat can never change the outcome. Reproduce one check, and say so in the remark.
  - **`CityState.UnderSiege` stays.** Other code reads it. Remove only its use in this gate.
  - **Rebellion is T89's.** The rebellion caller of `FUN_0044C204` also skips capitals, and T89's Done-when 2 covers that. Don't touch it here.
