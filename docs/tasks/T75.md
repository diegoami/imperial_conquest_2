#### T75 A new game opens as the original does: starting relations and the news seed

- **Design milestone**: none. It is a correction for bug [#322](https://github.com/diegoami/imperial_conquest_2/issues/322), and completes what `docs/tasks/T42.md` assigned to T29's export. **Labels**: `phase:2 lane:data local-only`
- **Branch**: `task/T75-new-game-seed` · **Model/effort**: Sonnet / Medium · **Reviewer**: **Opus / Medium**
- **Start after**: T68, T73 · **Merge after**: T68, T73. It runs **after the v0.3.0 tag**, by the user's decision of 2026-09-24; #322 is listed as a known issue in the v0.3.0 review brief. It is **never in flight with T67**, which owns another line of `GameStateFactory.cs`, **or T74**, which re-homes the `Export/**` tests' collection.
- **Owns**:
  - `src/IC2.Engine/Model/World.cs` and `src/IC2.Engine/Model/GameDataSchema.cs`: **two new optional world fields only** (starting relations and starting news)
  - `src/IC2.Engine/Model/GameStateFactory.cs`: **only** the `Relations:` and `NewsLog:` initialisers (~:171–174) and a helper they call
  - `scripts/export-classical-world.cs`, and `data/worlds/classical-mediterranean.json` regenerated through it, never edited by hand
  - `tests/IC2.Engine.Tests/Model/**`: new files only; `tests/IC2.Engine.Tests/Export/ExportedWorldTests.cs`: new assertions only
- **Scope**: The original's DAT loader reads a starting relation matrix and a 40-slot news seed, and new-game init keeps both (setting the news index to 26). Our `GameStateFactory` opens every game at uniform peace with an empty log.
  - **Relations**: DAT nation-record `+0x0B`, 16 × 16 shorts. It is symmetric with a zero diagonal and holds 5 wars, 13 trades, 4 alliances and no cooldowns ([`decompiled-diplomacy-peace-terms-and-instant-battles.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/decompiled-diplomacy-peace-terms-and-instant-battles.md), its 2026-09-24 addition).
  - **The news seed**: the DAT's last 2,440 bytes; slots 0–26 are scripted 272–271 BC history, slots 27–39 are empty, and the index is 26, set by the EXE ([`news-log-format-and-messages.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/news-log-format-and-messages.md) §Q1: "a reimplementation must load them verbatim").
  - **Both belong in the world file**, beside `startingArmies` and `startingFleets`, because they are DAT data like those. T73 parses both from the DAT.
- **Done when**:
  1. **The world carries both.** The world schema gains two optional fields: a starting relation matrix keyed by nation id, and a starting news log (its slot texts and newest index). A world that omits them opens at uniform peace with an empty log, so every toy world and every test built on one is unchanged; show that with the existing suite, unmodified.
  2. **Validation.** Loading a world rejects, with a typed error: a matrix that is not symmetric; a non-zero diagonal; a value outside the ruleset's relation codes and cooldown range; a nation id not in the world; a news text over the ruleset's message length; a news index outside −1 … slots − 1.
  3. **The export writes them from the DAT through T73's parse**, never typed by hand. The exported `classical-mediterranean.json` carries the DAT's matrix (with a test asserting Rome–Gaul at war, Rome–Macedonia trading, and the counts 5 / 13 / 4) and the 27 seed lines verbatim with index 26 (a test asserting slot 0 and slot 26 by their bytes). Each field has a `_provenance` citing the reports above. A second export run reproduces the file byte for byte.
  4. **A new game opens with them.** `GameStateFactory` on the classical scenario gives the DAT's relations and the 27-line log. A test starts a new classical game, ends one full round, and shows the round's date header follows slot 26 without duplicating it. It also shows that a war in the starting matrix is a war to the attack-legality check.
  5. **Downstream is named.** The PR lists every test, fixture and golden file that builds a **classical** new game and changes because of this (for example `tests/fixtures/cli/demo.golden.txt`, if its scenario is classical), each with the reason. A file outside Owns that changes is a stop-and-report, never a quiet regeneration.
  6. `dotnet build IC2.sln` and `dotnet test IC2.sln` are green, and the diff lists only Owns paths.
- **Hazards**:
  - **The AI now starts at war.** Five wars on turn 1 change the classical-world AI's opening. Anything that measured the classical game at uniform peace (T65's stall measurement, any classical soak) is measuring a different game afterwards. Say so in the PR.
  - **Verbatim means byte for byte.** Slot 12 and slot 25 are a single space, and `"270 BC"` has a space that the engine's own header format does not. Do not trim, and do not regenerate these lines through the news writer.
  - **Not the scenario.** Seats, victory and the turn limit stay in the scenario file. The seed describes the world at 270 BC, whoever plays it.
- **Constraint**: `local-only`. The export reads the original DAT.
