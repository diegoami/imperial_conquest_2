#### T150 An implementer run survives a benign outside path, keeps its brief, and has a second family to fall back on

- **Design milestone**: none. Process tooling, from the churn retrospective [#854](https://github.com/diegoami/imperial_conquest_2/issues/854): T140 took six implementer dispatches, two lost-work incidents and a main-session rewrite, mostly because the OpenCode guard's `ask` auto-rejected a benign path outside the worktree and ended the run. The user put it in the v0.5.0 gate on 2026-10-08 and asked for it before any other gate task. **Labels**: `lane:infra single-instance release:v0.5.0`
- **Branch**: `task/T150-implementer-churn`, from `origin/main` · **Model/effort**: Sonnet / Medium ([§3.3](../build-process.md#33-model-selection): not architecture, so the OpenCode default, then Sonnet) · **Reviewer**: the complex tier ([§3.4](../build-process.md#34-why-the-reviewers-model-differs-from-the-implementers)), GPT-6 Sol at `low`
- **Start after**: plan PR [#856](https://github.com/diegoami/imperial_conquest_2/pull/856) (the Godot-shim allow this task builds on) · **Merge after**: none. It is **never in flight with** another task or fix under `scripts/*OpenCode*`, `scripts/external-*.ps1`, `scripts/Choose-Model.ps1`, `.opencode/**` or `.github/workflows/**`.
- **Owns**:
  - `scripts/external-implement.ps1`;
  - `scripts/Invoke-OpenCodeWatched.ps1`: **only** what reports the outside paths a run touched (Done-when 3);
  - `.opencode/agents/external-implementer.md` and `.opencode/agents/external-reviewer.md`: **only** the `external_directory` block;
  - `.github/workflows/ci.yml`: **only** the `godot-headless` job's check steps;
  - `docs/environment.md`: **only** the lines describing the OpenCode agents' permission block, if they need to follow Done-when 3.
- **Scope**:
  - **Protects**: no game code, data, ruleset, test fixture or CLI golden changes. The guard still asks for every path outside the worktree except those Done-when 3 names, and `auth.json`, key files and the private fixtures stay unreachable. No reviewer's family rule changes ([§3.4](../build-process.md#34-why-the-reviewers-model-differs-from-the-implementers)): the fallback picks a different implementer, never a reviewer.
  - **Out of scope**: the review script's chain, the Claude agents, and any change to which model reviews which tier.
- **Done when**:
  1. **The brief lives in the worktree.** Before it starts OpenCode, `external-implement.ps1` copies `-BriefFile` to `rendered/brief.md` inside the worktree it made (git-ignored there) and names that path in the prompt. An absolute `-BriefFile` in the main checkout no longer appears in the prompt. `-WhatIf` prints the copy's destination.
  2. **A different family when the chain is spent.** When every model of the run's chain fails (today's exit 3), and before falling back to the main session's Claude Sonnet, the script asks `scripts/Choose-Model.ps1 -Role implementer` for the best-ranked model whose **family** differs from every model that failed in this run (the family map `Choose-Model.ps1` already reads), and runs it once. An explicit `-Model` gets the same second chance. If no such model has quota, exit 3 is unchanged. `-WhatIf` prints the model that would be chosen and why, and the run log and PR body name the substitute ("mm-m3 failed: permission-rejected; ran glm (zai) instead").
  3. **A benign outside path no longer ends the run** (the user's decision of 2026-10-08, #854 Fix 4). In both agent files, `external_directory` allows `C:?Users?diego?.local?*` and the user's TEMP directory (`C:?Users?diego?AppData?Local?Temp?*`), and then, after those allows (last match wins), **denies** `*auth.json*`, `*?.ssh?*`, `*ic2-test-fixtures*`, `*assets.local.ini*` and `*.env*`. Every other outside path still asks. OpenCode has no "warn and continue", so the warning is the script's job: after the run, the watcher lists every allowed outside path the session touched, reading the session export, and the script prints that list and appends it to the PR body under "Outside paths touched". It prints "none" when the list is empty. Appendix A's rule (stay inside the worktree, no scratch in TEMP) still holds; this only stops a slip from ending the run.
  4. **Every headless check runs in CI.** The `godot-headless` job runs each `*Check.tscn` under `godot/Checks/` and `godot/Screens/Checks/` as the existing three are run, failing on a non-zero exit or a `FAIL` line. A scene that cannot run on the CI runner (one that needs `assets.local.ini` or the private fixtures) is listed in the workflow, each with a one-line reason, and skipped. The list is in the PR body.
  5. **The proofs, in the PR body:**
     - (a) a `-WhatIf` run showing 1 and 2;
     - (b) one real run, on the cheapest available model, whose one-line prompt reads `C:\Users\diego\.local\bin\godot.cmd` and writes a file under `%TEMP%`: it completes, and the PR body lists both paths;
     - (c) the same run asked to read the scripts' `auth.json` is rejected, and the watcher classifies it `permission-rejected`;
     - (d) a run whose prompt names `C:\Windows\win.ini` still asks and is rejected;
     - (e) the CI run of 4, green.
  6. All three scripts parse, `dotnet build IC2.sln --nologo -v q` and `dotnet test IC2.sln --nologo -v q` are green, and `git diff --name-only origin/main...HEAD` lists only Owns paths.
- **Hazards**:
  - **Credentials.** Never read, print or log `auth.json` or any key (the user's standing rule). Proof 5(c) asks OpenCode to read it so the deny can be seen to hold; the run must be rejected before anything is read, and its transcript is not attached.
  - **The deny list is the safety net for 3.** Test each deny pattern against both separators before the real runs.
