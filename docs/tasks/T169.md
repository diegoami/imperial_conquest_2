#### T169 One theme for the whole app: the chosen fonts, a compact type scale and the new palette, and no Godot splash

- **Design milestone**: M18 (the Godot screens). Planned from [#899](https://github.com/diegoami/imperial_conquest_2/issues/899) and the user's choice at [T168](T168.md)'s review; the user's priority of 2026-10-12 for `v0.6.0`. **Labels**: `lane:ui release:v0.6.0`
- **Branch**: `task/T169-ui-theme`, from `origin/main` · **Implementer and reviewer**: the user's choice ([CLAUDE.md](../../CLAUDE.md) rule 17)
- **Start after**: [T168](T168.md) **and the user's pick** (the fonts, the palette and the type scale, recorded in `docs/investigations/ui-redesign-evaluation.md`'s last section and named in this entry by a plan edit before dispatch). **The user's pick of 2026-10-12, recorded in that section:** pairing A (Cinzel + Source Sans 3), the Bronze Night palette, and the type scale of the evaluation's section 4 as proposed. **Never in flight with** any task or fix that edits `godot/UI/**` or `godot/Screens/**` (T127, #1067, #1069, #1070 among them), because this task touches every screen.
- **Owns**:
  - `godot/Assets/Fonts/**`: the chosen font files with their licences (moved from `candidates/`; the candidates not chosen are removed).
  - `godot/UI/UiKit.cs` and a new `godot/UI/AppTheme.cs` (or a `Theme` resource beside it): one Godot `Theme` holding the fonts, the type scale and the palette, applied at the root, with `UiKit`'s helpers reading it.
  - The styled surfaces found by the pre-flight of 2026-10-12 (`git grep -l -E "AddThemeFontSizeOverride|new Color\(|UiKit\.Make|fontSize" -- godot`, checks excluded), **only** their font, size, spacing and colour literals, which move to the theme: `godot/MapViewer.cs`, `godot/Slice/Slice.cs`, `godot/Screens/{BattleEndedScreen,BattleResultScreen,DiplomacyScreen,GameEndScreen,HotseatHandoffScreen,ModalOverlay,PeaceOfferScreen,TacticalBattleScreen}.cs`, `godot/UI/{AboutDialog,AreaMapView,CommandToolbar,ConfirmPrompt,ContextPanel,GameMapView,GameMenuBar,HelpPage,LoadGameScreen,MainGameScreen,MainMenu,NewsLogPanel,RulesetChooserScreen,ScenarioSeatScreen,SettingsScreen,UnitCommandStrip}.cs` and `godot/UI/Dialogs/{ArmyTransferDialog,BalanceSheetDialog,BuildFleetDialog,ChangeUnitsDialog,EndTurnBox,FindCityDialog,FleetTransferDialog,FortifyDialog,RecruitMercenariesDialog,RecruitUnitDialog,RepairDialog,SplitArmyDialog,SplitFleetDialog,SupplyDialog,TaxationDialog}.cs`. A colour that carries game meaning (a nation's colour, a terrain colour, a marker tint) is not a theme colour and stays where it is.
  - `godot/project.godot`: **only** `application/boot_splash/*` (the Godot splash replaced by the game's own boot image or none) and the project's default theme setting.
  - `docs/asset-specification.md`: **only** a new section recording the chosen fonts, their licences and sources, and the palette.
  - `godot/Checks/DialogFitCheck.cs` and `.tscn` (new): opens every dialog under `godot/UI/Dialogs/` and every screen under `godot/Screens/` at the minimum supported window size and asserts each one's content fits its window (no control outside the visible rect, no clipped label).
  - Headless checks that assert a size, a colour or a layout the theme changes (`godot/Checks/ContextPanelWidthCheck.cs`, `MapClipCheck.cs`, and any other the run finds), **only** those assertions, each change explained in the PR; and the screenshot tours, which the main session re-runs and posts.
- **Scope**:
  - **Protects**: what every screen shows (its text, its figures, its order of controls) is unchanged; only the type, the spacing and the colours change. No command, rule or saved field changes.
  - **The rule**: every surface draws its fonts, sizes, spacing and colours from the one theme; no font size or UI colour literal is left in the owned files (a search shows it). The type scale is compact: the army panel (T140's fields) fits its fields with the scale and line spacing chosen at T168's review, and the transfer dialog's font follows the same scale (#1070's font item).
  - **Out of scope**: the city markers' three colours (#912, a separate task); the transfer dialog's totals and supply clarity (#1070's other items) and the recruit maximum (#1069): separate fixes after this task. The tactical battle and battle-ended screens are included only for font, size, spacing and UI colour literals; their game colours, text, control order and commands stay unchanged.
- **Done when**:
  1. **One theme:** a search of the owned files finds no `AddThemeFontSizeOverride` with a literal size and no UI colour literal outside the theme; the theme holds the chosen fonts, scale and palette.
  2. **The chosen fonts ship** under `godot/Assets/Fonts/` with their licence files, and the release export includes them (`scripts/package.ps1 -Verify`'s screenshot shows the display face on the main menu).
  3. **Compact:** the army panel shows all of T140's fields at the chosen scale in less height than before (a check measures it), and every dialog and screen fits its window at the minimum supported window size of **1366 x 768 physical pixels** (the user's decision of 2026-10-16; the 1500 x 850 design viewport and approved type scale remain unchanged): the new `DialogFitCheck` asserts it for each one, and `ContextPanelWidthCheck` and `MapClipCheck` stay green.
  4. **No Godot splash** at boot.
  5. **The user's visual sign-off** on the re-run screenshot tours (the main session posts them; [release-plan.md §5](../release-plan.md#5-release-checklist) item 18 for `v0.6.0`).
  6. Build, test and every headless check are green, and the diff lists only Owns paths.
- **Why it stays whole** (build-process.md §4.11): one theme applied everywhere is one change; split by screen, the app would show two looks between merges.
- **Hazards**:
  - **Game colours are not theme colours.** The nations' colours, terrain and marker tints stay where they are; moving them into the UI theme would let a palette change recolour the map.
  - **Before dispatch**, the main session re-runs the pre-flight (Appendix C step 0): the styled-file list above was taken on 2026-10-12, and UI fixes merged since may add files.
