- **Issue / release:** [#1805](https://github.com/diegoami/imperial_conquest_2/issues/1805), [v0.10.2 / milestone 27](https://github.com/diegoami/imperial_conquest_2/milestone/27). - **Workflow:** current `docs/cloud-mode.md`; work in the supplied checkout on `task/T284-illustrated-action-icons`. Scope/claims merge before implementation. No worktrees, author/reviewer model tiers or inherited desktop dispatch requirements.
- **Reference:** private original manual chapters 2 and 7 for toolbar meanings/tooltips, through the operating guide. Observer and QOL controls are owner-designed additions. Use only our own authored art as model references; original-game media stays private and never enters model requests, git or releases.

**Scope**

1. Inventory active strategic, tactical and observer action bars. Cover Play/resume, Pause, Skip current activity, battle reports (currently Latest battles), Next round, Watch civilizations, Take control, Undo, army/fleet Split in Two, Retreat and supply, army/fleet rally and clear-rally actions. Check remaining text-only/monochrome actions and record their disposition. Preserve meaningful labels for values, menus and dialog choices. The owner's phrase “all battles” requests an icon for the existing report action, not a new history policy.
2. Generate one coherent colored icon family with the configured Gemini image model through OpenRouter. Reuse the established config/API adapter in `scripts/generate-authored-assets.py`; introduce explicitly scoped UI keys rather than regenerating existing packs. Dry-run the selected prompts/model/cost before billable calls. No silent provider/model fallback; never print secrets or put them on command lines. Preserve raw outputs and model/prompt/hash provenance, with repeatable offline conformance and reachable artifacts.
3. Use transparent, crisp artwork readable at actual 24/32px and modern DPI. Match the game's authored visual style with clear silhouettes and consistent weight. Produce a contact sheet on Parchment, Dark, High contrast and Slate, including normal/hover/pressed/focus/disabled states. Inspect at actual size; fix unclear or cluttered symbols before integration.
4. Integrate through the shared icon/asset paths. Preserve illustration colors instead of flattening them through the old monochrome tint. Keep tooltips, accessible names, focus, enabled/disabled behavior and shortcuts. Play/Pause images and descriptions must follow current playback state in strategic and tactical observer controls.

No credentials or original media are included. Explicit UI generation leaves all unrelated authored assets unchanged.
2. Actual-size theme/state sheets show distinct, recognizable icons with clean transparency and readable state cues. Generated images replace text/monochrome fallbacks in the intended action bars; tooltips/accessibility and dynamic Play/Pause state remain correct.

Update the operating guide/asset documentation where needed. Native save formats, existing settings and original-SAV compatibility remain unchanged.
