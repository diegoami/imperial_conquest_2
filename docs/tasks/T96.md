- **Scope**: the main game screen's last-command label shows, **visibly**, what the last command did. Before #484 it always showed the trailing blank line. PR #521's two rounds got the text right: the command's own outcome block, cut at the round footer's `News:` header, blank-safe, keeping a composed declaration of war. The display was wrong:
  - **(a) Invisible.** A Godot 4 `Label` with autowrap plus clipping or an overrun behaviour reports a minimum size of (1, 1). The label sat in the root VBox at 1 px tall with 0 visible lines, the #484 symptom again. The re-review's layout probe measured it; the tests read only `.Text`, so they stayed green.
  - **(b) The wrong end.** `MaxLinesVisible = 3` shows the *first* three lines. For an `end`, whose block is about 17 lines (the human's own line, one line per AI seat, weather, then `Now: Week …, Active seat: …`), that hides the `Now:` line.
  - **(c) The prelude.** `GameSession.Submit` puts the pending prelude (the AI turns played before a non-first human seat's first order) *above* the `> command` echo line. The block scanned from the top, so a non-first seat's first order was buried under AI-turn lines.

  The decision (main session, 2026-09-29): **the block starts after the `> ` echo line** (the prelude is not part of a command's outcome), and **the label shows the block's last lines**. That means up to 3 visible lines, the full block in the tooltip, and a minimum height of three lines so the label is never collapsed.
- **Done when**:

It then asserts on the real label that `GetVisibleLineCount()` is between 1 and 3, and that the label's laid-out height is at least three lines' height. It covers an accepted order, a rejected order, an `end`, and a 1,000-character line. It fails on `c073ab2` and passes after.
  2. After an `end` as Rome, the label's **visible** lines include the exact `Now: Week …, Active seat: …` line read from the real `Submit` output, asserted in the headless check on what is visible (for example the lines past `LinesSkipped`), not only on `.Text`. It fails on `c073ab2` and passes after.
  3. A real-`Submit` test seated as a **non-first** nation (for example Thracia, in a new classical-mediterranean game) issues a first order and asserts that the label's text is that order's own outcome only, with no AI-turn prelude line. It fails on `c073ab2` and passes after.
  4. PR #521's resolved behaviour stays pinned, each by a real-`Submit` test:

     - whitespace-only lines are ignored;
