#### T164 Join units joins every selected unit, as the original does

- **Design milestone**: M18 (the Godot screens), with the engine command it submits. - **Scope**:
  - **Protects**: a Join units order over any number of selected units of one type gives one unit holding all their troops, or is refused whole, never a partial join.
  - **The rule** ([`2026-10-11-g2-original-checks.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/2026-10-11-g2-original-checks.md) C5 and correction 2, **[confirmed: Wine, li]** **[code: `TChangeArmyUnits_JoinUnits`, dump 45584-45683, every type]**): the original sums **every** selected unit, keeps the **first selected** slot, removes the others, and sets the kept unit's quality to the **integer average** of all the selected units' qualities. It refuses the whole order, with today's messages, when any selected unit is not regular, when the types differ, or when the total exceeds the type's battalion size (R44). Played: three li of 1,000, 1,200 and 1,500 became one of 3,700; four (with 1,700) became 5,400; two (1,000, 1,200) became 2,200 and the 1,500 stayed.
  - **The average's rounding**: the report did not observe it (every staged unit had quality 6). Keep today's `[derived]` truncation, `sum / n` in integer division, generalised from the two-unit case; the implementer states it in the handler's remark.
  - **Compatibility**: the two-index `join-units <army> <a> <b>` line keeps working unchanged, so the CLI goldens' existing join lines and the AI's pairwise joins produce the same result as today.
  - **Out of scope**: the original applies the join when the Change units dialog is closed with OK; the clone keeps applying it on the Join press. Split and Rename (#721).
- **Done when**:
  1. **All selected are joined.** The report's three cases through the command: 1,000 + 1,200 + 1,500 → one unit of 3,700 in the first selected slot; the four-unit case → 5,400; the two-unit case → 2,200 with the third untouched. Each fails on `origin/main` (or does not compile there, and the reviewer judges that the behaviour is absent).
  2. **Refused whole.** A selection with one mercenary, with mixed types, or whose total exceeds the battalion size is refused with today's rejection code, and the army is unchanged; a test pins each.
  3. **Quality.** Three units of qualities that do not divide evenly join to `sum / n`, truncated; a test pins it.
  4. **The dialog submits every selected unit.** `JoinUnitsLine` with three indexes gives one `join-units` line naming all three, and the line through `GameSession` produces Done-when 1's result.
  5. **Nothing regresses.** Build, test and all Godot headless checks are green, the existing two-unit joins (CLI goldens, AI) give the same results, and the diff lists only Owns paths.
