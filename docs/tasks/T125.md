- **Scope**:
  - **Protects**: that every battle the original auto-resolves (AI against AI in the field, every siege, every naval battle) keeps `InstantBattleResolver`'s outcomes and draws exactly; that with `HumanBattles = Instant` (the default) every existing transcript, golden, check and soak is byte-identical; and that, under `Tactical`, a field battle with a human side is never resolved by the instant path, and no save is written while a battle is open. Forbidden: an edit to `InstantBattleResolver`, `BattleCasualties` or `AttackArmyCommandHandler`'s instant branch; a re-baselined golden; a save, autosave or `save` command that succeeds during a battle; a write-back that skips the peace dialog or draws it before the promotions.
  - **The branch** **[confirmed: code: `decompiled-diplomacy-peace-terms-and-instant-battles.md` §"The original's instant battle resolver"; `game-design.md`, "When the battle screen opens"]**. With `HumanBattles = Tactical`, a human's `attack-army` whose legality passes (`AttackLegality`, unchanged) and whose attacker or defender nation has a `Human` seat zeroes the attacker's moves and opens the battle (T123's copy-in) instead of dispatching `AttackArmyCommand`. A battle with no human seat, every `besiege` and every `attack-fleet` go through the existing commands, unchanged. With `Instant`, nothing changes. **The default is `Instant`** [designed: an engineering switch, so that the merge changes no existing behaviour; T127 sets `Tactical` in the Godot UI]. Whether the player is offered the choice is **[open: #496]**.
  - **The battle's orders**, as CLI verbs and as `GameSession` methods for T127: `battle show`, `battle place <unit> <x> <y>`, `battle move <unit> <x> <y>`, `battle attack <unit> <enemy>`, `battle shoot <unit> <enemy>`, `battle clear <unit>`, `battle end`, `battle general on|off`, `battle surrender` (with the confirmation), each mapping to one human order of T123 [designed: the verbs]. While a battle is open, every other line except `help` and `quit` is refused with a message. A computer-played half-round (the defender's placement, an AI side's moves, a side under *Computer general*) runs at once through T124's general.
  - **The draws.** One `IRng` stream per battle, derived from the state's seed and a stable battle key (`battle.tactical:<attackerArmyId>:<defenderArmyId>:<turnIndex>` [designed]). The write-back reaches `GameState` through `ApplyTacticalBattleCommand`, dispatched like any command, so `RngStreams`' documented advance points stay the only ones.
  - **The end** ("Write-back"). T123's write-back (steps 1–5), then step 6 through the existing T88 path: the peace treaty offer between a human and an AI side, gated on `armies(W) < armies(L)`, `unity(L) > 500`, `cities(L) > 7` and `Random(5) < 2`, the draw taken from the battle's stream after the promotions; between two human seats, the existing hotseat payment path. The `TacticalBattleReport` goes to `SessionOutput` for the *Battle ended* window. Every turn-level consequence that follows a battle today (elimination checks, victory, the news log) runs as after an instant battle.
  - **Saves** **[designed: the user's decision of 2026-10-04 on #496]**: while a battle is open, `save` (and so the UI's Save and Save As) is refused with a message, under both presets. The probe's observation that the original's File → Save As does write a mid-battle save **[Wine candidate: [`2026-10-04-battle-probe.md`](https://github.com/diegoami/imperial-conquest-2-research/blob/main/docs/reports/2026-10-04-battle-probe.md) item 2]** is posed on #496, not acted on here.

- **Hazards**:
  - **No task changes `InstantBattleResolver`'s outcomes for battles the original still auto-resolves.** The branch sits in the session, before dispatch; the instant path is called exactly as today when it applies. A shipped seeded value that moves is a stop-and-report.
  - **The decoupling guard.** No file under `src/IC2.Engine/Battle/**` may reference the diplomacy namespace (`FieldBattleTests.AssertNoBattleSourceReferencesDiplomacy`): the peace step lives in `TacticalBattleSession.cs`, under `Presentation`.
  - **The AI phase is not this task's.** If an AI seat's turn attacks a human army, it still resolves at once (T116's option A) until T126. Do not suspend the AI loop here.
  - **`HumanBattles` is a session switch, not a rule.** It is never saved and never in a ruleset; a reloaded game takes the switch of the session that loads it. A save cannot happen mid-battle, so a battle is never reloaded.
  - **The default stays `Instant`** so that the Godot UI keeps working on `main` between this merge and T127's; if the review or the user wants the CLI default changed, that re-baselines goldens and is a follow-up, not a change here.
  - **Never add the original's File → Save As in a battle**: it is a question on #496.
