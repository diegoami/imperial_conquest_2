# T234 — Staged diplomacy choices

Owner decision 2026-10-28: diplomacy choices remain pending until OK and Cancel discards them, following the private original manual §9.2. Addresses #1560; uses T233's safe transient editing support.

## Contract

- Show current/pending relation choices without changing authoritative relations, offers, cooldowns, treasury, news, events or RNG. Replacing/clearing a nation's pending choice must not retain side effects of the discarded choice.
- Keep war confirmation, incoming-offer validity, legal/refusal feedback and Faithful/Improved command rules. Stage a final per-nation intent and replay the validated plan deterministically in displayed nation order; replacing a choice reconstructs preview from the opening snapshot.
- OK validates the complete plan before commitment. Refusal/stale context leaves all authoritative state unchanged and the dialog open. Cancel/Escape closes and discards everything. Successful commit reports outcomes and refreshes once; no double application.
- No original research parity or new legality rule is inferred from the UI change. No save schema changes; pending choices are transient.
