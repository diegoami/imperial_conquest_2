#### T289 Independent right-side strategic panels and compact toolbars

Owner request [#1818](https://github.com/diegoami/imperial_conquest_2/issues/1818), v0.11.0; [layout design](../design/v011-panel-layout.md).

**Scope:** MainGameScreen layout, StrategicPanels, CommandToolbar, AreaMapView, CompactToolbar and real-control checks. Four independently hideable frames: Overview map (location/filter strip above the map), Selected object, News, Log. A named checked-toggle strip stays outside the column. Each frame has a close button that returns keyboard focus to its reopen toggle. All hidden releases the column width. F12/global hide preserves panel choices; arriving information never opens the globally hidden column. Explicit reopen shows the column. No new disk preference or campaign-save field.

**Content:** preserve existing ContextPanel selection/information permissions and NewsLogPanel ordering, dismissal, handoff and formatting. Log retains the existing latest command-result block, with its existing three-line tail and whole-block tooltip; no new rolling history, battle history or diagnostic content. Its scrolling viewport can accommodate constrained heights. The owner's optional history preference is separate from this retention-preserving layout.

**Sizing:** proportional heights Overview 2, Object 1.6, News 1.2, Log 0.7 after compact headers; hidden frames have no reserved area. Overview has a scroll viewport when its contents cannot fit; selected-object and News retain their own scroll controls. Main and overview pictorial buttons use 24px artwork inside 32px targets with 4px padding, preserving themed state borders/colors/focus. Two-pixel toolbar gaps and wrapping on narrow main toolbars reduce actual footprint, not just art size. Missing-icon captions remain available.

**Reference:** private manual chapter 2, “The four windows”, toolbar/Area map entries and `M02_32_main_screen_rome_area.png`: separate Area/Unit maps and contextual Information, nation choices affect viewing rather than active-seat orders. This owner-requested right column and independent News/Log arrangement is the explicit layout exception. Original save-stored window placement is not a new persistence requirement here.

**Done when:**

1. All sixteen visibility combinations fit, all hidden widens the map, and reopen controls remain reachable. Global hide/reopen preserves choices and selection. New news respects dismissal/global hide.
2. Real city/army/fleet inspection, hotseat privacy and observer controls keep working. Panel actions issue no campaign commands and leave state/RNG unchanged.
3. Four themes and 1500×850 / 1000×650 logical layouts (the latter at 150% in window captures) are checked; compact button bounds, disabled state, focus and tooltips remain usable. Captures are authored UI only.
4. IndependentPanelsCheck and existing SidePanelToggleCheck, CommandFeedbackCheck, news, context, map and observer/hotseat checks pass. CI automatically discovers the new Check scene. Green exact-head CI before merge.
