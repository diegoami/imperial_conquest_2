## Contract

Owns the faithful army scheduling seam in `AiTurn`/`AiMilitaryPhase`, a transient army-table cursor, regression tests and factual docs. Within `ClassicalArmyNavigation.Applies`, capture the physical table count (live records plus dead slots) at military entry, before capital defence. Process each eligible own army's commands, contact and fallback before advancing the table index. Later armies read earlier actions' live state. Skip missing/dead/non-own/ineligible records safely; do not run appended records beyond the captured count or revisit an earlier army. No cross-army score competition or tie draw.

Preserve command legality, honest counters, the existing action safety cap and deterministic tactical suspension/replay. Improved/custom-world selection, upfront economy/support/hire and the existing non-army proposal/phase placement remain unchanged. The diagnostic first-candidate filter is evidence, not a production implementation. E84C's missing same-army continuation is separately owned by #1652; do not claim that one-march behavior or global phase interleaving is corrected here. No saved fields or settings.

## Done when

1. Real-dispatch tests fail before and pass after: a later army's higher-scoring attack waits until the earlier army completes its approach/contact, and later targets reflect earlier kills. Reverse IDs/table order independently and pin command order, state and zero rejections.
2. Exercise zero/dead/foreign records, entry-count bounds and appended records, no-op fallback, live death and battle replay. Prove no cross-army selection draw, deterministic rerun and unchanged Improved selection.
3. Run AI, legality/determinism, diplomacy, native export and CLI regressions, solution build and full hosted CI. Preserve seeds, commands and the pinned treaty fixture when attributing transcript changes.

The study compares 679 first actions on 16 starts × five rounds, one seed: main matches 668 and the diagnostic 678, with the remaining row following an earlier battle outcome. Research reran its classifier on existing logs, not the diagnostic build. No full-campaign, identical-RNG, later-round, hunt or native Windows parity follows.
