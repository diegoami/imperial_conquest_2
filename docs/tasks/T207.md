### Scope

Add a second Settings tab named **Automation**. Existing appearance, map, sound, battle and control options remain on the first tab. The new global `user://settings.json` fields have separate, default-off switches for army auto supply and auto funding, a supply target percentage (0–100, default 100), a purse target in talents (default the shipped purse cap of 1,000, clamped to the active ruleset cap when used) and a nonnegative treasury reserve (default 1,000). Existing settings files load with both automations off. Show the active settings clearly in game; a native save opened on another machine uses that machine's global settings, so tests and diagnostics must record them when comparing play.

On a confirmed human End turn, plan for that seat's armies in state order. For each army, use `SupplyProviders.ForArmy` to choose **own** free city/fleet/army providers in its reported order; an owned nearby fleet and an embarked army's carrying fleet are positive cases. Never silently buy from a foreign city. Buy only enough tons to reach the configured share of the engine's current army capacity, bounded by live provider stock and the existing `buy` command. For funding, transfer from the nation's treasury toward the configured purse target without crossing the treasury reserve or the ruleset's purse/move cap, through the existing `transfer-money` command. Re-read live state after each accepted command, never mutate records directly, and report skipped/refused/partial actions with a reason. The settings off path issues no extra commands or RNG advances.

The warning box retains its existing pre-confirmation behavior. **Make more moves** or Cancel runs no automation. Both End turn routes (with and without a warning box) share one confirmed path: auto commands, a visible compact summary, then one ordinary `end`. A repeated End turn attempt must not duplicate a completed top-up; a partial top-up may proceed if stock or treasury later changes. No automation runs during an open battle, an AI seat or a foreign selection. Global policy changes apply to the next confirmed End turn, not retroactively.
