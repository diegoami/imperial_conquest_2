#### T215 Per-unit Retreat and supply mode

- **Issue**: [#1403](https://github.com/diegoami/imperial_conquest_2/issues/1403). This is a player QoL mode, not the original strategic AI resupply selector [T213](T213.md). Release allocation is a separate owner decision.
- **Owner decisions (2026-10-24)**: the mode is assigned to an individual army or fleet; it keeps choosing owned supply destinations, favoring capitals and larger towns, and moves onward when still undersupplied. An army **or fleet of a nation at war** within inclusive Chebyshev distance 10 cancels it for either unit type. Splitting is a suggestion only: open the existing strength-balanced Split in two dialog, allow the player to edit whole-unit allocation, and submit no split until they confirm. Completion requires full supplies and, for fleets, full condition; army funding is best effort and does not hold the mode open. Eligible owned towns rank capital, then population, then distance. Enabling the mode asks before replacing an existing fixed travel target.
- **Owns**: optional campaign-local mode records on `SaveGame` and `GameSession`; native save/load and original-SAV omission reporting; pure army/fleet destination and danger planners under `godot/UI/Automation/`; selected-unit controls and the confirmed End-turn pass in `MainGameScreen`; focused engine, persistence and Godot checks. Reuse T205's `SplitArmyDialog`, T207/T208 support planners, and T211's command/lifecycle pattern. `MovementWalker`, command eligibility, classical rules, combat, original SAV bytes and unrelated AI passes are read-only.

### Scope

A human player enables or cancels the mode on one owned unembarked army or launched fleet. The mode works in any season; winter is a common use, not an automatic activation trigger. Enabling it does not immediately issue a command. A unit may have either this mode or a fixed T211 travel target; the UI shows the active plan and asks before replacing one with the other. The mode is default-off in all older saves and original SAV imports, independent of the global automation toggles. It targets full supply capacity and, for fleets, the ruleset's maximum condition; use the player's current purse target and treasury reserve for best-effort army funding and fleet repair cost.

On each confirmed End turn, visit active human-seat units in saved state order. Re-read state after each accepted move, supply, funding or repair command; never mutate game state directly or issue attack, siege, war, embark or disembark. One unit gets at most one move command per pass. Run this pass after mobilization/recruitment and before global auto support and the single `end`; skip units under another hotseat nation, open battle, missing/changed owner, embarked army or unlaunched fleet. A manual order for the same unit cancels the mode. Show destination, resource gains/cost, progress, refusal and stop reason in the turn summary. With no active plans, issue no additional commands or RNG draws.

At the start of a unit's pass and again after any move, check for armies or fleets belonging to nations currently at war with that unit's nation. Either kind of danger within inclusive Chebyshev distance 10 cancels the mode before further automated action, with a visible reason, for armies and fleets alike. Never use the original AI's destination scorer for this player policy.

The destination planner considers owned towns that the unit can approach through ordinary movement and that can provide currently usable supply or fleet repair. Rank a capital first, then larger population, then shorter distance, then stable city ID; skip a town that cannot service the present deficit and avoid revisiting a spent town until its resources change. An army may draw supply from an eligible owned army or fleet at its present location; a fleet may supply and repair at eligible owned towns. If no eligible destination remains, stop visibly without inventing a route. A route blocked or refused by the real command stops the mode; no automatic attack or ferry is attempted.

Finish the mode when an army's supplies reach full capacity, or a fleet's supplies reach full capacity **and** condition reaches the ruleset maximum. Army money top-up is best effort and does not delay completion. A suggested split button for a large army invokes the existing editable `OpenSplitArmyDialog(suggestBalanced: true)` path; the turn pass never splits by itself. The suggestion should show why dividing whole units could improve supply, and Cancel leaves army and mode unchanged. If the player confirms a split, the new army does not inherit the mode implicitly.

Persist optional per-unit records keyed by nation, unit kind and ID. Older native JSON saves with no records load with none; a different save replaces the list. Invalid/stale records drop with a visible reason rather than making a save unloadable. The original-compatible SAV exporter reports active mode records as omitted QoL metadata and never refuses solely because of them. Save/load and export must leave unit state and RNG unchanged.

4. Godot checks exercise enable/cancel controls, route and progress display, danger cancellation, the editable split suggestion, confirmed End-turn ordering and exactly one `end`. A cancelled split submits no command.
5. Build solution and Godot project, run focused tests and relevant headless scenes, then full CI green. Record test counts and any machine-only acceptance limits.
