#### T293 Eleven historical campaigns (contract and decomposition)

Owner request [#1808](https://github.com/diegoami/imperial_conquest_2/issues/1808), v0.11. Scope, the eleven openings and their dates are fixed by [v011-campaigns-and-random-maps.md](../design/v011-campaigns-and-random-maps.md#historical-starts). **This page defines the delivery contract; no scenario data exists yet and none is claimed.**

**Pattern to reuse (verified):** the Near East campaigns are authored offline and reproducibly by `tools/NearEast/build_campaigns.py` from committed public source subsets (Pleiades, CC BY 3.0) into `data/worlds/*.json`, a terrain PNG/sidecar and `data/rulesets/*.json`; a guide in `data/campaign-guides/` ([T290](T290.md)) must exist per campaign. The classical navigation tables apply only to `classical-mediterranean` (320×140), so every new world uses the generic AI policy, as Italy and the Near East already do.

**Maps (reuse where extent and scale fit, otherwise author):**

| Campaign group | Map |
|---|---|
| Persia c.550 BC, 480 BC | extend/reuse the Near East map (276×185 at 8×10 tiles per degree) plus the Aegean; needs checking that 480 BC's Greek theatre fits |
| Mediterranean 431, 280, 218 BC | the Mediterranean world; the 431 BC opening must cover the whole sea. Reuse `classical-mediterranean` geography only if its scale suits (decision 1) |
| Diadochi 323, 301 BC | Near East plus Aegean/Macedon/Egypt, same family as Persia |
| India c.325, c.185 BC | **new map** (no existing geography) |
| China c.350, 230 BC | **new map** (no existing geography) |

**Per-campaign deliverable (each is one task, order below):** a brief with sources and every abstraction labelled; authoring script and committed source subsets; world, terrain, ruleset and guide; seats and starting diplomacy; calendar and end year (no inherited 250 BC hard stop); terrain per the [terrain-authoring rule](../design/terrain-authoring.md) with a pass plan; test evidence: deterministic data validation, viable openings for every playable seat, several-round AI play, save/load, copied-package launch, and a guide with provisional advice. The 280 BC campaign must use one consistent snapshot.

**Proposed order** (cheapest first, each one shippable alone): (1) Diadochi 323 and 301 on the existing Near East geography; (2) Persia 550 and 480; (3) Mediterranean 431, 280, 218; (4) India ×2; (5) China ×2. The two new maps (India, China) are the largest cost: each is a geography-sourcing task on its own.

**Owner decisions, 2026-11-09:** v0.11 is **staged** (ship the first N that pass acceptance, in the order above, the freeze deciding); the Mediterranean campaigns get a **new map**, not the classical 320×140 world. Troop roles (decision 2): **existing roles with authored names and art, labelled as abstractions; no new rules**.

**Questions asked:**
1. Mediterranean map: reuse the classical 320×140 world (reusing its seat/city data risks inheriting classical-only rules) or author a new one.
2. Troop roles: Indian war elephants and Chinese crossbows/chariots need roles the ruleset may lack; new roles or rules are a design decision, not an authoring one (default: use existing roles with authored names and art, labelled as abstractions).
3. Whether v0.11 must ship all eleven or the first N that pass acceptance; the recommendation is the staged order above, with the milestone freeze deciding.

**Done when (this contract task):** reviewed, decisions answered, one issue per campaign created and linked from #1808.
