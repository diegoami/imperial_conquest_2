#### T98 The OpenCode scripts on the 2.x CLI

- **Design milestone**: none. Process tooling: the OpenCode desktop app bundles the 2.x CLI and moved the shared database to its schema on 2026-10-01 (bug [#540](https://github.com/diegoami/imperial_conquest_2/issues/540)), and npm publishes no 2.x yet. **Labels**: `lane:infra single-instance`
- **Branch**: `task/T98-opencode-2x` · **Model/effort**: Sonnet / Medium · **Reviewer**: **Opus**/Medium
- **Start after**: none · **Merge after**: fix #540 (it edits `scripts/Invoke-OpenCodeWatched.ps1` too). It is **never in flight with** another task or fix under `scripts/*OpenCode*`, `scripts/external-*.ps1` or `.opencode/**`.
- **Owns**:
  - `scripts/Invoke-OpenCodeWatched.ps1`;
  - `scripts/external-implement.ps1`;
  - `scripts/external-review.ps1`;
  - `.opencode/agents/external-implementer.md`;
  - `.opencode/agents/external-reviewer.md`.
- **Scope**: the scripts run OpenCode **1.x** today (the npm `opencode-ai` package). They run with their own data directory since fix #540. The 2.x CLI (`%APPDATA%\ai.opencode.desktop\cli\<version>\opencode-cli.exe`, 2.0.18 on 2026-10-01) differs where the scripts depend on it:
  - **`run --dir` is gone.** The working directory is the process's own (`Start-Process -WorkingDirectory`).
  - **Variants.** `--variant <v>` is gone; the variant is part of the model, `provider/model#variant`.
  - **The background service.** By default `run` talks to a shared background service. The watcher must own and kill the process that does the work, so it passes `--standalone`.
  - **Permissions** are the V2 model. The agents' permission blocks in `.opencode/agents/` must say the same thing in V2 terms: allow inside the worktree, deny outside. `--auto` is never passed. A V2 agent in the global config broke every 1.x run on 2026-09-30, so the two must not be mixed.
  - **Rejection detection.** `Get-OpenCodePermissionRejection` (issue #505) parses 1.x output. It must recognise a 2.x rejection and still classify it `permission-rejected`.
  - **Session detection.** `session list --format json -n <n>` still returns `id`, `title`, `directory` and `created` (checked on 2.0.18). Confirm that `export <session>` exists and keep it.

  **Which CLI runs.**
  - `IC2_OPENCODE_EXE` still wins.
  - Otherwise use the newest `opencode-cli.exe` under the desktop app's `cli\` folder, then the npm CLI.
  - The scripts read `--version` once. They build 1.x or 2.x arguments by the major version, log which version runs, and fail with exit 3 and a clear cause on an unknown major version.
  - 1.x stays supported, because a machine without the desktop app has only npm.
  - The data directory from fix #540 is kept for both versions.
- **Done when**:
  1. With the 2.x CLI, one watched run on the free model `opencode/mimo-v2.6-flash-free` and a one-line prompt, in a worktree, creates a session that the watcher detects. It exits 0 and the transcript export is written. The PR shows the log lines.
  2. With the 2.x CLI, a run whose prompt asks it to read a file outside its worktree is rejected, and the watcher classifies it `permission-rejected` (the #505 class), with the rejected path in its message.
  3. The argument line for a variant model (glm with `high`) is `--model opencode/glm-5.3#high` under 2.x and `--model opencode/glm-5.3 --variant high` under 1.x. A `-WhatIf` style switch prints it without starting OpenCode or billing a model, for both versions.
  4. The idle timeout still kills the whole process tree under 2.x: a run with a 10 s idle timeout and a prompt that waits leaves no `opencode-cli` process behind.
  5. With `IC2_OPENCODE_EXE` pointing at the npm 1.x executable, Done-when 1 still passes.
  6. All three scripts parse without errors, `dotnet build IC2.sln` is green, and the diff lists only Owns paths.
- **Hazards**:
  - **Credentials.** Never read, print or log `auth.json` or any key (the user's standing rule). Copying it is fine.
  - **Billing.** Every Done-when run uses the free model. `external-review.ps1 -DryRun` still bills a model today, so don't use it as the no-billing check; that is what Done-when 3's switch is for.
  - **The desktop app's own database.** Never write to `~/.local/share/opencode/opencode.db`.
  - **Concurrency.** Never run two OpenCode sessions at once.
  - **Docs.** This is a `lane:infra` change to process tooling, so the implementer edits no Markdown under `docs/`. Its PR's "Docs affected" names the operating-guide and build-process lines about the npm CLI, and the main session applies them after the merge.
