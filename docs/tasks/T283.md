# T283 — Selected-civilization observer playback

Owner request and decisions, 2026-11-05, #1784: watch one or more civilizations, follow their strategic movement at a readable pace, show full tactical battles fought automatically by both computer generals, and configure speed. Fast-forward unwatched activity. This extends T278 rather than claiming its original report-only observer already provides these features.

## Contract

- Add a multi-civilization watch chooser separate from the paused nation-takeover picker. Watched armies/fleets have paced map playback and an optional camera-follow control; unwatched routes skip presentation. Pause/Play/Next round, inspection, save/load-to-paused and safe takeover remain available.
- Provide visible observer speed controls affecting map and battle playback, with a readable slow default and validated persisted UI preferences. Watching selection/speed/camera never changes simulation orders, RNG or results. Keep timing outside rules/state and do not seed from time.
- Use one explicit observer battle policy for all AI field battles: the full-tactical option runs existing TacticalBattleSession/ComputerGeneral rules for both watched and unwatched fights. Capture/play the actual tactical frames when either nation is watched; unwatched fights run the same rules without animation. Keep legacy instant observer/CLI watch as an explicit control. Full tactical outcomes can differ from instant resolution; this is a designed observer policy, not original AI fidelity.
- Resolve each AI-vs-AI tactical encounter inside its ordinary dispatch and continue the same AI turn exactly once. Do not reuse the human pending-battle same-seat replay, repeat diplomacy/economy/support, replace an open human battle, or alter normal human/legacy CLI behavior. Reuse current copy-in, driver, write-back, event/report and timeline facilities rather than inventing combat formulas.
- Reuse the tactical board/exchange/list/audio presentation as a read-only automatic replay. Pause/speed/skip/close control presentation only; board clicks and shortcuts cannot issue human battle orders or Undo. Show existing clearly labelled siege/naval results where a watched encounter has no tactical board; do not invent naval/siege tactical mechanics.
- Preserve route/battle order and exact-once reports, frames and audio across strategic playback, automatic battle overlays, manual pause, round completion, modal/file/close boundaries and takeover. Queue complete immutable batches before later commands can replace Last* output. No background simulation thread or silent stalled loop.
- Existing save schema, original-SAV policy and game data stay unchanged. Observer battle policy and speed are explicit session/UI preferences; loading resumes paused. Save during presentation uses the actual authoritative campaign, never a reconstructed display state.
