#### T291 Open Imperial Conquest naming sweep

Owner request [#1814](https://github.com/diegoami/imperial_conquest_2/issues/1814), v0.11. The remake is called **Open Imperial Conquest** everywhere the maintained product names itself. A trailing `@` in the request was a typing slip.

**Contract (bounded):** change presentation names only. No rule, RNG, save, AppId or identifier change. Published tags and release assets are never rewritten: new releases use the new asset prefix, old ones stay as published.

**Coverage checklist.** Result: **changed**, **kept** (reason) or **later**.

| Surface | Result |
|---|---|
| Main menu, About dialog, Godot `config/name` | already Open Imperial Conquest |
| Help ▸ About menu row (`GameCommandTable`) | changed: "About Open Imperial Conquest" |
| Map viewer window title (`MapViewer.cs`) | changed |
| Diagnostics journal `product` field | changed |
| README title | changed |
| Installer publisher, default install folder, script heading | changed. The default folder applies to **fresh installs only**: Inno reuses an existing install's directory for the same AppId |
| Installer / zip filename prefix | changed to `OpenImperialConquest-` in `installer/ic2.iss`, `scripts/release-assets.ps1`, `release.yml`, `docs/packaging.md`; new releases only |
| Installer `AppId` | **kept**, fixed forever (upgrade identity) |
| Assembly/project names (`IC2.*`, `IC2.MapViewer.exe`), repository name, namespaces, `installer/ic2.iss` path | **kept**: technical identifiers; renaming breaks paths, integrations and saves for no player-visible gain |
| `UserDataMigration.FormerAppName` and migration marker | **kept**: they name the former folder on purpose; migration unchanged and tested |
| Original game: "Imperial Conquest 2", `Imperial Conquest 2.dat`, `.HLP`, evidence docs, main-menu subtitle "A reimplementation of Imperial Conquest 2, the 1996 strategy game" | **kept**: they name a different work |
| `scripts/installer.iss` | **kept**: unreferenced legacy copy; deletion is a separate cleanup |
| Historical task/plan documents | **kept**: record of what was true then |
| `.github` templates/workflows mentioning "Imperial Conquest 2" | **later**: maintainer-facing, no player surface |

**Done when:** scoped searches (`src godot tests scripts installer .github README.md docs/packaging.md`) leave only the classified rows above; unit tests and the Godot checks pass; installer test still finds the unchanged AppId; fresh-install and upgrade are checked by reading the Inno script (no uninstall of the owner's install).
